# kbar-lit

A Lit / Web Components reimplementation of [timc1/kbar](https://github.com/timc1/kbar).

Under development: a framework-independent action store, a Lit reactive controller,
and a customizable `<kbar-palette>` element. No React runtime.

## Development

```sh
npm install
npm run dev
```
